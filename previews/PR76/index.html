SetProg

SetProg is a JuMP extension for Set Programming : optimization with set variables and inclusion/containment constraints. This package allows the formulation of a mathematical programming involving both classical variables and constraints supported by JuMP and set variables and constraints.

Set families

SetProg supports the set families Ellipsoid(symmetric = true), PolySet(symmetric = true, degree = 4), and Polytope. Polynomial sets require using SumOfSquares to load the optional extension.

Polyhedral configurations share linear pieces and polar operations:

simplex = Polytope(piecewise = :orthant)
box = Polytope(piecewise = :orthant, polar = true)
weighted_l1 = Polytope(symmetric = true, piecewise = :orthants)
parallelotope = Polytope(symmetric = true, piecewise = :orthants, polar = true)
conic = Polytope(symmetric = true, piecewise = cones)

A matrix in cones has generating rays as columns. Symbolic partitions infer the dimension from the model. polar describes the requested set family; it does not impose a modeling space. Constraints select that space as usual. On :orthant, the polar is restricted to the nonnegative orthant.

Set evaluation is available on fitted sets through V(x). Certificate construction and normalization are provided by PathCompleteCertificates.

SetProg.Polytope — Type
Polytope(; symmetric = false, dimension = nothing, piecewise = nothing,
         transform = nothing, polar = false, min_scale = nothing)

A polyhedral set variable. piecewise can be a partition polytope, a vector of matrices whose columns generate partition cones, :orthant, or :orthants. The symbolic partitions have one positive-orthant linear piece or a weighted absolute-value sum, respectively. transform maps their rays into state coordinates. For symbolic and explicit-cone partitions, polar requests the polar family. On :orthant, polarity is restricted to the nonnegative orthant (blocking duality). These options describe the family and do not prescribe a modeling space. For symbolic and explicit-cone partitions, min_scale bounds the piece coefficients away from zero and defaults to one when omitted.
